# Independent usability check

Status: not yet performed by an independent person. Automated browser checks do not count as user feedback.

Ask an event planner to try the app with their own email and the public fictional document sample. Do not ask them to contact a real venue unless they have a genuine enquiry.

Tasks:
1. Create an event with a neighbourhood, menu and budget.
2. Find one venue source and explain whether availability has been confirmed.
3. Upload the fictional PDF without sending mail.
4. Find the calculated total, open the original and identify the GST rate.
5. Change guest count, export the comparison and return after signing out.

Record whether each task was completed without help, where they hesitated, any wrong assumptions, and what they would need before using it for an actual event. Ask permission before publishing their name, quote or screenshot. Store private responses outside this repo; publish only consented, anonymized findings.
