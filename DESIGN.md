# One Table design

Preserve Claude's paper-white comparison surface and deep green accent. This is an operational tool: figures, quoted terms and original evidence matter more than decoration. No generated imagery.

Use a readable system sans, tabular monetary figures, clear separation between confirmed totals and uncertain quotes, real table semantics, responsive stacked rows on small screens, visible keyboard focus and reduced-motion support. Row movement communicates an actual change in ranking.

The public example must say it is fictional. Private event and reply states must name whether data was pasted, received, queued, extracted or failed. Provider configuration is not a delivery receipt.

## Landing page and demo, September 8

The public landing surface uses warm paper, forest-green actions, Georgia editorial headings and a working quote-comparison preview. Sage and oat panels frame factual example content. Typography and spacing carry the identity; no generated imagery, invented customer endorsements or savings statistics.

The landing route explains the product, shows missing-term handling, and answers pilot/privacy questions. `#demo` contains only fictional saved extraction results and mock original replies; it performs no provider calls or writes. `#workspace` opens the existing authenticated private application. Navigation uses shareable hashes and browser history. Motion is limited to the first comparison preview and respects reduced-motion preferences.


## Private workspace, September 9

Keep the same warm paper, forest green and editorial headings. The saved-events home leads to a two-step brief. Event work is split into Shortlist, Compare quotes and Replies & documents views. Use flat venue rows, progressive disclosure for sources and reply forms, and a compact verified-account bar. Avoid exposing provider setup details in the main product flow.

## Shared control conventions

Use restrained, low-saturation accents on the existing paper or slate surfaces. Buttons use 4px vertical and 8px horizontal padding, a 4px corner radius, a 6px content gap, and 16px icons. Preserve readable labels and visible keyboard focus. The shared rules live in `controls.css`; illustrations retain their natural dimensions.
